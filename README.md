# GALE-CAST design gallery

A picture gallery of the GALE-CAST website front-end design. It is **not** the working website: every image is a screenshot.

- View the gallery: https://tinenen-cs.github.io/gale-cast-design-gallery/
- The real website: https://gale-cast.vercel.app

Shows the current design (live since October 13, 2026), following the order of the GALE-CAST User Manual: whole pages, first-visit questions, every Home feature, the Gale Alert (High, Moderate, both, many areas, TEST ONLY survey alerts), notification settings, Public Readiness, About, offline and error screens, and the menu and footer. 278 pictures on desktop 1440, laptop 1366, tablet portrait 820 and landscape 1180, phone 390 and small phone 320, in light and dark. Whole pages and close-ups use the real GALE-CAST forecast at capture time; the alert pop-ups, the High and Moderate days and slow loading use sample data.
