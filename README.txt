GALE-CAST DESIGN GALLERY
========================

What this is
  A picture gallery of the GALE-CAST website's front-end design.
  It is NOT the working website. Every image is a screenshot and the
  numbers shown are sample data, not real forecasts.

How to open it
  1. Keep this folder together: index.html and the "images" folder must
     stay side by side.
  2. Double-click index.html. It opens in your web browser.
  3. No internet connection is needed.

How to use it
  - Buttons in the dark bar at the top show one theme (light or dark)
    or one device (phone, tablet, desktop).
  - Click any picture to open it full size.

The real website
  https://gale-cast.vercel.app
